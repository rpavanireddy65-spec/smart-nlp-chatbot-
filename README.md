🤖 Smart NLP Chatbot

An interactive Natural Language Processing (NLP) based chatbot built using HTML, CSS, and JavaScript. The chatbot understands common user queries and provides relevant responses through a modern and user-friendly chat interface.

✨ Features

- 💬 Interactive chat interface
- 🧠 Basic NLP and intent-based query processing
- ⚡ Real-time chatbot responses
- 🤖 Automated bot replies
- ⌨️ Enter-key message support
- 💡 Quick-question buttons
- 🕐 Message timestamps
- ⌨️ Typing indicator
- 🗑️ Clear chat option
- ➕ New conversation option
- 😊 Emoji support
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and modern user interface

🛠️ Technologies Used

- HTML5 – Structure of the chatbot
- CSS3 – Styling, layout, animations, and responsive design
- JavaScript – Chat functionality and NLP-style query processing

🧠 How It Works

The chatbot follows a simple query-processing approach:

User enters a message
        ↓
JavaScript receives the message
        ↓
Text is converted to lowercase
        ↓
Keywords and user intent are identified
        ↓
Matching response is selected
        ↓
Chatbot displays the response

For example:

User: What is NLP?

SmartBot:
NLP means Natural Language Processing.
It helps computers understand and process
human language.

🎯 Project Objective

The main objective of this project is to demonstrate how a chatbot can process natural-language-style user queries and generate appropriate responses using web technologies.

It also provides a foundation for developing a more advanced AI chatbot using machine-learning or external AI APIs.
